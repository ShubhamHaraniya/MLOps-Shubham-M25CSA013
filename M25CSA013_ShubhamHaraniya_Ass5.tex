\section{Q1: ViT-S Fine-tuning on CIFAR-100 with LoRA}

\subsection{Overview}

We take a Vision Transformer Small (\texttt{vit\_small\_patch16\_224}) pre-trained on ImageNet and fine-tune it on CIFAR-100 (100 classes). Two strategies are compared:
\begin{enumerate}
    \item \textbf{Baseline}: Only the classification head (100-class linear layer) is trainable.
    \item \textbf{LoRA}: Low-Rank Adaptation via PEFT is injected into the Q, K, V attention weights with a trainable classification head.
\end{enumerate}

\subsection{Setup}

\begin{itemize}
    \item \textbf{Base model}: \texttt{vit\_small\_patch16\_224} (timm, ImageNet pretrained)
    \item \textbf{Dataset}: CIFAR-100, resized to $224\times224$, ImageNet normalization
    \item \textbf{Epochs}: 10, \textbf{Batch size}: 64, \textbf{Optimizer}: AdamW
    \item \textbf{LoRA targets}: \texttt{qkv} projection in every ViT attention block
    \item \textbf{Dropout}: 0.1 for all LoRA experiments
\end{itemize}

\section{Key Observations \& Analysis}

\subsection{Q1: LoRA vs Baseline}

\begin{itemize}
    \item The baseline (only head fine-tuned) reaches \textbf{77.46\%} val accuracy and \textbf{76.57\%} test accuracy with only 38,500 trainable parameters ($<$0.2\% of model).
    \item LoRA fine-tuning consistently outperforms the baseline across all rank/alpha combinations, with the best grid result being Exp 6 (r=4, $\alpha$=8): \textbf{89.26\%} val, \textbf{89.15\%} test.
    \item Higher $\alpha$ values (relative to rank) consistently improve accuracy — the scaling factor $\alpha/r$ appears more important than rank alone.
    \item Increasing rank beyond 4 yields diminishing returns while increasing parameter count significantly.
    \item Optuna found rank=16, $\alpha$=16 as the global optimum, achieving \textbf{90.20\%} with 333,412 trainable params (1.51\% of model).
    \item LoRA shows significantly faster early convergence: LoRA Exp 1 achieves \textbf{81.72\%} val accuracy at epoch 1, compared to the baseline's \textbf{68.52\%}.
\end{itemize}

\subsection{Q2: Adversarial Attacks \& Detection}

\begin{itemize}
    \item FGSM is highly effective even at small $\varepsilon = 0.01$, dropping accuracy from 93.12\% to 46.31\% (a drop of 46.81 points).
    \item The accuracy under attack continues to degrade monotonically with increasing $\varepsilon$, reaching 18.70\% at $\varepsilon = 0.30$.
    \item The IBM ART FGSM uses a different evaluation protocol (2000-sample subsets), but shows comparable degradation patterns.
    \item PGD and BIM detectors train extremely quickly — by epoch 2, both detectors reach $>$97\% val accuracy — suggesting that iterative attacks (40 iterations) create highly structured, detectable artifacts.
    \item Both detectors achieve near-perfect ROC-AUC, meaning there is essentially zero overlap between the clean and adversarial feature distributions learned by ResNet-34.
\end{itemize}
